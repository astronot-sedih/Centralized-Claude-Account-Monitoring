# Plan 03 — Quota Collector Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read every Claude account's quota and write one snapshot per account,
fail-soft per account, without tripping the usage endpoint's 429.

**Architecture:** Reuses the existing `getClaudeUsage` service and the existing
refresh routine rather than reimplementing either. Accounts are polled
sequentially with a delay. Error strings are scrubbed of anything token-shaped
before they are persisted.

**Tech Stack:** Plain ESM JavaScript, vitest with injected fakes (no live calls).

**Spec:** `docs/superpowers/specs/2026-10-28-centralized-claude-monitoring-design.md` (§5.2, §5.4, §7)

**Global Constraints:** see `2026-10-28-00-overview.md`.

## Review Focus

Covered here:
- An expired token / failed refresh is persisted as `ok = 0` and must not abort
  the other accounts → Tasks 2, 3.
- A 429 across 11 sequential accounts must not hammer or crash → Task 3.
- A token must never reach a persisted error string → Task 1.

### Task 1: Token scrubbing

**Files:**
- Create: `src/lib/monitoring/scrub.js`
- Test: `tests/unit/monitoring-scrub.test.js`

**Interfaces:**
- Produces: `scrubSecrets(text) -> string` — replaces anything token-shaped with
  `[redacted]`. Non-string input returns `""`.

This is its own task because every other task depends on it and it is the one
piece where a mistake is a credential leak rather than a wrong number.

- [ ] **Step 1: Write the failing test**

```js
import { describe, expect, it } from "vitest";
import { scrubSecrets } from "../../src/lib/monitoring/scrub.js";

describe("scrubSecrets", () => {
  it("redacts Anthropic-shaped tokens anywhere in the string", () => {
    const tok = "sk-ant-oat01-" + "A".repeat(80);
    expect(scrubSecrets(`refresh failed for ${tok} at step 2`))
      .toBe("refresh failed for [redacted] at step 2");
    expect(scrubSecrets(tok)).not.toContain("sk-ant");
  });

  it("redacts bearer headers and long opaque blobs", () => {
    expect(scrubSecrets("Authorization: Bearer abc123def456ghi789jkl012mno345pqr"))
      .not.toMatch(/abc123def456/);
    expect(scrubSecrets("eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxMjM0NTY3ODkwIn0.dBjftJeZ4CVP"))
      .toBe("[redacted]");
  });

  it("leaves ordinary error text intact", () => {
    expect(scrubSecrets("HTTP 429 rate limited, retry after 180s"))
      .toBe("HTTP 429 rate limited, retry after 180s");
    expect(scrubSecrets("token expired")).toBe("token expired");
  });

  it("returns empty string for non-string input", () => {
    expect(scrubSecrets(null)).toBe("");
    expect(scrubSecrets(undefined)).toBe("");
    expect(scrubSecrets({ a: 1 })).toBe("");
  });
});
```

  instead of defining `refreshAndUpdateCredentials` locally; keep re-exporting
  it so existing importers are unaffected)
- Test: `tests/unit/monitoring-credentials.test.js`

**Interfaces:**
- Consumes: `getProviderConnectionById`, `updateProviderConnection` from
  `@/lib/localDb`; `getExecutor` from `open-sse/executors/index.js`;

- Produces: `refreshAndUpdateCredentials(connection, force, proxyOptions) -> Promise<{ connection, refreshed: boolean }>`

tokens before refreshing, and its own comment records why — refreshing from a
stale snapshot can revoke the whole token family and log the account out. A
second implementation would eventually lose that.

### Task 3: The collector

**Files:**
- Create: `src/lib/monitoring/quotaCollector.js`
- Test: `tests/unit/monitoring-collector.test.js`

**Interfaces:**
- Consumes: `getProviderConnections` from `@/lib/localDb`;
  `getClaudeUsage` from `open-sse/services/usage/claude.js`;
  `refreshAndUpdateCredentials` (Task 2); `insertSnapshot` (Plan 02);
  `scrubSecrets` (Task 1); `resolveConnectionProxyConfig` from
  `@/lib/network/connectionProxy`.
- Produces:
  - `collectOnce(deps = {}) -> Promise<{ attempted, ok, failed }>` — `deps` lets
    tests inject fakes for every collaborator above; production passes nothing.
  - `resolveSource(connectionId, dateKey, deps) -> Promise<"9router"|"desktop">`
    — `"9router"` when `usageHistory` holds a row for that connection that day,
    honouring a `providerSpecificData.monitoring.sourceLabel` override.

Key behaviours fixed by the spec: sequential polling with a delay between
accounts (`COLLECT_DELAY_MS = 1500`), never pass `force: true` to
`getClaudeUsage` (the 5-minute cache and 3-minute 429 cooldown are
protections), and one failure must not abort the run.

- [ ] **Step 1: Write the failing test**

```js
import { describe, expect, it, vi } from "vitest";
import { collectOnce, resolveSource } from "../../src/lib/monitoring/quotaCollector.js";

const conn = (id, extra = {}) => ({
  id, provider: "claude", isActive: 1, name: id, email: `${id}@t.io`,
  accessToken: "sk-ant-oat01-" + "x".repeat(60), ...extra,
});

describe("collectOnce", () => {
  it("writes one snapshot per account", async () => {
    const inserted = [];
    const r = await collectOnce({
      getProviderConnections: async () => [conn("a"), conn("b")],
      refreshAndUpdateCredentials: async (c) => ({ connection: c, refreshed: false }),
      getClaudeUsage: async () => ({ plan: "Claude Code", quotas: { "session (5h)": { used: 5 } } }),
      insertSnapshot: async (s) => { inserted.push(s); return inserted.length; },
      resolveSourceFor: async () => "desktop",
      delay: async () => {},
    });
    expect(r).toMatchObject({ attempted: 2, ok: 2, failed: 0 });
    expect(inserted.map((s) => s.connectionId)).toEqual(["a", "b"]);
    expect(inserted[0].ok).toBe(1);
  });

  it("keeps going when one account's refresh throws, and records it as a failed read", async () => {
    const inserted = [];
    const r = await collectOnce({
      getProviderConnections: async () => [conn("bad"), conn("good")],
      refreshAndUpdateCredentials: async (c) => {
        if (c.id === "bad") throw new Error("Refresh token invalid or reused.");
        return { connection: c, refreshed: false };
      },
      getClaudeUsage: async () => ({ quotas: { "session (5h)": { used: 1 } } }),
      insertSnapshot: async (s) => { inserted.push(s); return inserted.length; },
      resolveSourceFor: async () => "9router",
      delay: async () => {},
    });
    expect(r).toMatchObject({ attempted: 2, ok: 1, failed: 1 });
    const bad = inserted.find((s) => s.connectionId === "bad");
    expect(bad.ok).toBe(0);
    expect(bad.errorMessage).toContain("Refresh token invalid");
  });

  it("persists a 429 as a failed read rather than throwing", async () => {
    const inserted = [];
    const r = await collectOnce({
      getProviderConnections: async () => [conn("a")],
      refreshAndUpdateCredentials: async (c) => ({ connection: c, refreshed: false }),
      // The service soft-fails with {message} instead of quotas on 429.
      getClaudeUsage: async () => ({ message: "Claude connected. Unable to fetch usage: 429" }),
      insertSnapshot: async (s) => { inserted.push(s); return 1; },
      resolveSourceFor: async () => "desktop",
      delay: async () => {},
    });
    expect(r).toMatchObject({ attempted: 1, ok: 0, failed: 1 });
    expect(inserted[0].ok).toBe(0);
  });

  it("never lets a token reach the persisted error text", async () => {
    const tok = "sk-ant-oat01-" + "Z".repeat(70);
    const inserted = [];
    await collectOnce({
      getProviderConnections: async () => [conn("a", { accessToken: tok })],
      refreshAndUpdateCredentials: async () => { throw new Error(`bad token ${tok}`); },
      getClaudeUsage: async () => ({ quotas: {} }),
      insertSnapshot: async (s) => { inserted.push(s); return 1; },
      resolveSourceFor: async () => "desktop",
      delay: async () => {},
    });
    expect(inserted[0].errorMessage).not.toContain("sk-ant");
    expect(inserted[0].errorMessage).toContain("[redacted]");
  });

  it("polls sequentially with a delay, never in parallel", async () => {
    // 11 simultaneous calls on one endpoint is exactly what trips the 429.
    const order = [];
    const delay = vi.fn(async () => { order.push("delay"); });
    await collectOnce({
      getProviderConnections: async () => [conn("a"), conn("b"), conn("c")],
      refreshAndUpdateCredentials: async (c) => ({ connection: c, refreshed: false }),
      getClaudeUsage: async (tok, p, o) => {
        order.push("read");
        expect(o?.force).not.toBe(true);   // the cache and cooldown are protections
        return { quotas: { "session (5h)": { used: 1 } } };
      },
      insertSnapshot: async () => 1,
      resolveSourceFor: async () => "desktop",
      delay,
    });
    expect(order.filter((x) => x === "read")).toHaveLength(3);
    expect(delay).toHaveBeenCalled();
    expect(order.indexOf("delay")).toBeLessThan(order.lastIndexOf("read"));
  });

  it("skips connections flagged monitor-only? no — it must include them", async () => {
    // monitorOnly excludes an account from ROUTING (plan 04), never from
    // monitoring; that is the whole point of the flag existing separately
    // from isActive.
    const inserted = [];
    await collectOnce({
      getProviderConnections: async () => [
        conn("m", { providerSpecificData: { monitorOnly: true } }),
      ],
      refreshAndUpdateCredentials: async (c) => ({ connection: c, refreshed: false }),
      getClaudeUsage: async () => ({ quotas: { "session (5h)": { used: 3 } } }),
      insertSnapshot: async (s) => { inserted.push(s); return 1; },
      resolveSourceFor: async () => "desktop",
      delay: async () => {},
    });
    expect(inserted).toHaveLength(1);
  });
});

describe("resolveSource", () => {
  it("reports 9router when the connection has proxy rows that day", async () => {
    expect(await resolveSource("c1", "2026-10-28", {
      countUsageRows: async () => 12, getConnection: async () => ({ id: "c1" }),
    })).toBe("9router");
  });

  it("reports desktop when it has none", async () => {
    expect(await resolveSource("c1", "2026-10-28", {
      countUsageRows: async () => 0, getConnection: async () => ({ id: "c1" }),
    })).toBe("desktop");
  });

  it("honours an explicit override, so a Claude Code user who did not work that day is not mislabelled", async () => {
    expect(await resolveSource("c1", "2026-10-28", {
      countUsageRows: async () => 0,
      getConnection: async () => ({
        id: "c1", providerSpecificData: { monitoring: { sourceLabel: "9router" } },
      }),
    })).toBe("9router");
  });
});
```
